每一组的公开 molecule ID、source canonical SMILES、document、assay、vendor/protocol 描述及两套模型分数都一致。源结构重新计算的完整 InChIKey 也对应 56 个实体，未发现本次 62→56 是不同源结构被标准化合并造成。模型标准化结构仍有自己的立体信息局限，不能据此替代材料身份。

观察表中 `R1/R2` 的生成方式是：在相同 source record 中，各 endpoint 按 activity ID 排序后按出现次序配对。40 个重复组 endpoint 在原始 ChEMBL JSON 中逐条核对通过，activity ID 未重复使用，ER 也与 B→A/A→B 重建一致。但导出没有显式的方向配对 sample ID、独立实验日、浓度、孵育时间或材料批次。`R2` 因而只是重建观察索引，不能被宣称为生物独立重复。

建议以唯一化合物的 `median(log2 ER)` 给连续主报告，每个分子的分数只保留一次；62 行历史权重作为敏感性。对 CHEMBL5605022 保留两条原观察及阈值冲突。若做 ER≥2 的探索性二分类，既报告预先指定汇总规则，也可额外排除该冲突分子检查稳定性；不能从两个值挑出有利的一条。

本数据只有 MDR1-MDCK vendor assay，没有 matched parental 或 inhibitor rescue。它可检验冻结分数与这一体系的方向性，不能验证严格 ABCB1 底物身份、母体—释放物配对或完整 ADC。

## 统计结果的独立核验

另运行 `verify_asap_statistics_independent.py`，从旧的 source-held-out 预测 CSV 独立重建汇总，采用 `rankdata` 后的 Pearson 相关、显式成对 AUC 和混淆计数；没有导入主执行脚本的 helper。2000 次共同 Murcko scaffold 抽样按登记的 seed=20261009 重现。

**126 个数值及缺失值检查全部通过**。56 个实体上 v0.3−v0.1 的 Spearman 差为 −0.029427，95% 区间 [−0.264427, 0.165632]；62 行历史敏感性为 +0.018462，[−0.232924, 0.265448]。两个区间均跨零，因此这个来源没有证明 v0.3 的相关性稳定优于 v0.1。

两种人群、三种相同名额策略都只保留 5 个真实弱 ER 阳性，且均预测为阳性。没有真实负类，也没有低风险预测，BAcc 与 NPV 均正确保留为空，不能将这 5 个写成完美二分类验证。检查回执见 `independent_statistic_checks.csv`、`independent_statistics_verification.json`；原输入保持不变。
